# Design-FitCo
Proyek perancangan antarmuka aplikasi mobile FitCo (Panduan Latihan Kebugaran) yang dikembangkan untuk memenuhi Tugas Akhir Mata Kuliah nteraksi Manusia dan Komputer (IMK). Aplikasi ini dirancang dengan pendekatan User-Centered Design dan berfokus pada simplifikasi navigasi serta pengurangan beban kognitif bagi pengguna pemula hingga menengah.
